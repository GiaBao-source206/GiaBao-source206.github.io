## Về mình

Mình là **Nguyễn Văn Gia Bảo**, sinh viên năm 3 ngành **Thương mại điện tử** tại **UIT – ĐHQG-HCM**.
Mình thích chỗ kinh doanh gặp công nghệ, mê gym, chạy bộ và hay vọc vạch đồ công nghệ.

## Điểm nhấn

- **Chấm cam chạy theo cuộn trang** dọc vạch xanh. Chặng đang đọc sẽ đổi sang màu cam.
- **Dải xé có thể bấm được**, có đường răng cưa và vết khía như bib thật.
- **Responsive:** trên điện thoại, sơ đồ BPMN tự chuyển sang dạng dọc.
- Tôn trọng `prefers-reduced-motion`. Font tự host, hỗ trợ đầy đủ tiếng Việt.

## Công nghệ

HTML · CSS · JavaScript thuần, **không framework, không build**. Font Barlow / Barlow Condensed tự host. Trang chạy trên GitHub Pages.

## Chạy thử trên máy

```bash
git clone https://github.com/GiaBao-source206/GiaBao-source206.github.io.git
cd GiaBao-source206.github.io
python3 -m http.server 8000   # rồi mở http://localhost:8000
```

## Cấu trúc

```
index.html     # toàn bộ trang (HTML + CSS + JS)
fonts/         # Barlow, Barlow Condensed (latin + vietnamese)
docs/          # ảnh preview cho README
DESIGN.md      # hệ thiết kế: màu, chữ, thành phần
PRODUCT.md     # nội dung & nguyên tắc của trang
```
